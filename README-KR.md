# Smart Cart Autonomy Lab 1.1.1

[English](README-SIMULATION.md) · [시뮬레이터](simulator/index.html) · [모델 명세](simulator/docs/MODEL-KR.md) · [검증 결과](simulator/docs/QA-KR.md)

**Smart-Cart-4의 차체 비례·센서 배치·후륜 감속모터·전륜 서보 조향을 바탕으로 만든 사용자 추종 시뮬레이터입니다.** 사용자를 직접 이동시키면 카트가 UWB 추정 위치와 LiDAR·전방 ToF 관측으로 경로를 계획합니다. 미리 녹화한 주행이나 케이스별 자동 재생이 아닙니다.

## 1.1.1: 입력·후진 추종·경사 동작 수정

방향키와 모바일 버튼은 현재 시점의 **화면 방향**을 따릅니다. 시점을 회전해도 왼쪽 입력은 화면 왼쪽으로 이동하고, 일시정지 버튼에 초점이 남아도 이동키를 사용할 수 있습니다. 마우스 드래그는 오른쪽으로 방위각 증가, 위쪽으로 관측 고도 증가이며 입력란·모달의 기본 키 동작은 유지합니다.

가까운 측면 대상은 거리만 보고 무조건 정지하지 않고, 센서 추정을 유지하며 저속 위치·방향 회복을 수행합니다. 후진 조향 부호와 차체 중심/후륜축 경로 기준을 수정했고, 후방 관측·통과 가능 지형·전후진 전환 제동을 확인합니다. PDoA 경계에서는 잡음이 있는 두 원의 정확한 교점을 강제하지 않고, 이전 이동 예측과 두 거리 관측을 확률 가중 방식으로 갱신합니다. **처음부터 후방에 있는 대상의 거리 두 개만으로 방위를 만들어 내지는 않습니다.**

사람의 양발은 각각의 발바닥 영역 지면 높이를 기준으로 놓고 허벅지·종아리·신발을 분리해 두 관절 역기구학으로 연결합니다. 카트는 구동력·중력·마찰·제동력과 회전 관성의 등가 질량을 적분합니다. 가속도와 중력 성분을 우측 후륜 패널에 추가했으며, 구동력·제동력 및 CSV/JSON 기록에서도 확인할 수 있습니다. 자동 정지 후에는 주차 제동을 적용하므로 경사에서 정지 유지가 되는 것은 정상입니다.

## 계승한 1.1.0 화면 구성

[SANE](https://github.com/JTech-CO/SANE)의 작업 중심 구성, 읽을 수 있는 글자 크기, 의미 있는 색상, 상세 정보의 단계적 공개를 적용했습니다. **밝은 UI 한 가지**를 사용하며 다크모드 전환 기능은 없습니다. 저조도는 3D 시험 환경의 광원 조건일 뿐 웹 UI의 테마를 바꾸지 않습니다.

상단에서 환경을 선택하고, 중앙에서 사용자를 움직이며, 우측에서 센서·구동 데이터를 읽습니다. 주행 상태와 카메라 선택은 화면 위, 센서 표시 선택과 이동 안내·주행 요약은 화면 아래에 둡니다. 3D 화면을 덮던 상태·조작 박스는 제거했습니다. 기본 글자 크기는 16px, 주요 보조 문구는 14px이며 한국어와 숫자는 시스템 글꼴로 표시합니다.

우측의 현재 수치와 변화량은 항상 제공하고, 점군·최근 12초 그래프는 각 항목을 펼쳐 확인합니다. 후륜 모터·전륜 조향까지 세로로 이어지므로 작은 높이에서는 패널을 스크롤합니다. 좌우 그래프는 실선·점선으로도 구분하고, ToF 그래프는 숫자 표시와 같은 mm 단위를 사용합니다. 모바일에서는 시뮬레이션과 방향 버튼 아래에 데이터가 이어집니다.

상세 설정과 모델 안내를 열면 시뮬레이션을 일시정지합니다. 닫기·Esc만으로는 다시 움직이지 않으며 명시적으로 재개해야 합니다. **설정 적용 및 초기화**는 기존과 같이 새 세션을 시작합니다. 센서 가정·렌더링 품질과 고장 시험은 설정 안의 펼침 항목에 있습니다. 키보드로 버튼을 누를 때 Space가 두 번 처리되는 문제도 수정했습니다.

## 바로 실행

ZIP을 풀고 `simulator/index.html`을 엽니다. 루트 `index.html`도 같은 화면으로 연결됩니다. WebGL 2와 JavaScript가 필요하며 하드웨어 가속을 권장합니다. 모델·텍스처는 코드로 생성하고 모든 JS/CSS는 로컬 파일입니다. 서버, npm 설치, 빌드, API 키, 외부 CDN이 필요하지 않습니다. 조직 브라우저 정책이 로컬 파일을 차단하면 GitHub Pages로 배포합니다.

## 기존 저장소에 넣는 방법

압축을 푼 폴더 자체를 한 단계 더 넣지 말고, **폴더 안의 파일들을 `smart_cart_app` 루트에 복사**합니다. `simulator/`, 루트 진입 페이지, 테스트, Pages 워크플로가 추가됩니다. 원본 Flutter `lib/`, `web/`, Android·Windows 코드를 덮어쓰는 패키지가 아니며 기존 Flutter 전체 소스도 포함하지 않습니다. 원본 README와 라이선스를 보존하도록 문서는 `README-SIMULATION` 이름을 사용합니다.

저장소 **Settings → Pages → Build and deployment → Source: GitHub Actions**를 선택합니다. `Deploy Smart Cart Simulator` 워크플로는 코어 및 1.1.1 결함 회귀 테스트를 실행한 뒤 `simulator/`만 게시합니다. 기본 브랜치는 `main`입니다. 이미 다른 Pages 워크플로가 있다면 동시에 사이트를 덮어쓰지 않도록 먼저 정리해야 합니다. **이번 작업에서 원격 커밋·푸시·실제 Pages 배포는 하지 않았습니다.**

브랜치 배포도 가능합니다. **Deploy from a branch → main → /(root)**를 선택하면 루트 페이지가 `/simulator/index.html`로 연결합니다. Actions 방식은 사이트 루트에 시뮬레이터가 바로 표시됩니다. [상세 배포·연계 안내](simulator/docs/INTEGRATION-KR.md)를 확인하세요.

## 조작

| 동작 | 조작 |
|---|---|
| 태그를 가진 사용자 이동 | 방향키 또는 WASD, 모바일 방향 버튼 길게 누르기 |
| 관찰 방향 | 마우스 드래그 또는 터치 드래그 |
| 확대·축소 | 마우스 휠, 상단 카메라 모드 선택 |
| 추종 시점 복귀 | C |
| 일시정지·재개 | Space 또는 상단 버튼 |
| 비상정지 래치·해제 | E 또는 비상정지 버튼 |
| 환경 구성 | 상단 지형·장애물·광원 선택, 환경 세부 설정 |
| 측정 시각화 | 화면 아래의 LiDAR / UWB / ToF / 계획 경로 / 관측 지도 |
| 기록 저장 | 내보내기의 CSV / 세션 JSON / 텔레메트리 JSON / PNG / 설정 JSON |

이동 방향은 **현재 카메라의 수평 화면 좌표계**를 기준으로 합니다. 조작하는 대상은 카트가 아닌 사람입니다. 키보드 입력란·선택 상자를 조작할 때는 사용자 이동을 차단합니다. 탭 전환이나 포커스 이탈 시 입력을 비우고 일시정지하며 자동 재개하지 않습니다.

## 포함 기능

평지, 오르막, 내리막, 복합 경사, 6단 계단을 하나의 환경 모델로 구성했습니다. 계단에서는 사람만 올라가며 카트는 통과 금지 구역 앞에서 멈춥니다. 장애물은 없음/약간/많음과 기둥/사람/상자 조합을 선택합니다. 사람은 개별 목표와 회피 행동으로 움직이고, 상자는 질량·마찰·충격량을 갖습니다. 정상 추종은 상자를 피하려 하며, 상자 외란 또는 접촉 상황에서 이동과 제동을 확인할 수 있습니다.

인공 조명은 수직에 가까운 광원과 그림자 억제, 햇빛은 태양 고도·방위에 따른 그림자, 저조도는 낮은 조도를 적용합니다. 햇빛의 센서 영향은 실측 교정값이 아닌 **설정 가능한 스트레스 모델**입니다. UWB가 어둠 때문에 작동하지 않게 만들지는 않았습니다.

중앙에는 실제 3D 장면이 있고 우측에는 LiDAR 점군·유효율·최단 거리, 좌우 UWB 거리·방위·신호 상태, 전방 ToF 거리·유효 상태, 후륜 모터 회전수·추정 전류·기계 출력·PWM, 전륜 좌우 조향각·중심 명령이 세로로 표시됩니다. **우측 패널은 아래로 스크롤하면 후륜·전륜·상태 기록까지 이어집니다.** 그래프는 최근 12초의 실제 시뮬레이션 이력이며 무작위 장식 그래프가 아닙니다.

## 반드시 구분할 점

**실차 제어기나 안전 검증용 디지털 트윈이 아닙니다.** 센서 모델의 오차, 노이즈, 모터 토크·전류, 질량, 제동 등은 명시된 가정입니다. 계단 정지는 전방 ToF만으로 구현했다고 주장하지 않고, 미리 알려진 지형 제한과 별도 물리 접촉 제한을 사용합니다. 정지 후에는 가정한 유한 용량의 주차 제동을 적용합니다. 자유 구름 시험은 구동과 제동을 모두 해제한 별도 물리 회귀시험으로 구분합니다. 실차에서 접촉기만 개방해 같은 경사 정지를 보장할 수는 없습니다.

기존 Flutter 앱으로 실시간 전송하는 기능은 없습니다. 대신 원본 `telemetry.dart` 형태의 JSON을 저장합니다. 전방 ToF 배치에 맞게 `left_mm/right_mm`를 전방 좌·우로 해석하고 `cliff:null`을 보냅니다. 상세 내용은 [모델 및 한계](simulator/docs/MODEL-KR.md), [출처·가정](simulator/docs/SOURCES.md), [연계 안내](simulator/docs/INTEGRATION-KR.md)에 정리했습니다.

## 검증

`node tests/core.test.cjs`와 `node tests/bugfix.test.cjs`로 외부 의존성 없이 코어·결함 회귀 테스트를 실행합니다. 브라우저 테스트에는 별도로 Python Playwright가 필요합니다. [QA 문서](simulator/docs/QA-KR.md)는 자동화 결과와 브라우저 정책 때문에 확인하지 못한 항목을 구분합니다. 특정 경로의 무접촉 결과를 모든 시드·모든 사용자 이동에 대한 보증으로 일반화하면 안 됩니다.
