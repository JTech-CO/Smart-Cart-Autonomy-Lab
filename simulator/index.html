직접 이동하며 확인합니다.

방향키 또는 WASD는 카트가 아니라 UWB 태그를 가진 사용자를 움직입니다. 이동축은 지형에 고정됩니다. W·↑는 전방(+Z), S·↓는 후방(-Z), A·←는 좌측(+X), D·→는 우측(-X)입니다. 좌우는 초기 관측 방향에서 정하며, 카메라를 회전하거나 C로 시점을 복귀해도 바뀌지 않습니다. 키를 계속 누른 채 드래그해도 같은 지형 방향으로 이동합니다. 사람은 실제 이동 방향을 향하고, 발은 공중에서 앞으로 내딛고 지면 접촉 중에는 몸을 기준으로 뒤로 이동합니다. 오른쪽 드래그는 방위각을 늘리고 위쪽 드래그는 시점을 높입니다. 휠로 확대합니다. Space는 일시정지, E는 비상정지, C는 추종 시점 복귀입니다. 모바일 방향 버튼도 같은 고정축을 사용합니다. 상세 설정과 안내를 열면 일시정지하며, 닫아도 자동으로 재개하지 않습니다. 우측의 왼쪽 열은 현재 수치, 오른쪽 열은 최근 12초의 실시간 그래프입니다. 아래쪽 센서와 구동 항목은 스크롤로 확인합니다. 작은 휴대폰 화면에서는 그래프가 수치 아래로 이어지며, 펼치지 않아도 표시됩니다.

관측 → 지도 → 계획 → 구동

UWB 거리·방위 관측을 필터링해 사용자를 추정합니다. LiDAR와 전방 ToF의 관측으로 단기 점유 지도를 만들고, A* 전역 경로와 운동학적 후보 궤적을 평가해 조향·속도를 정합니다. 다른 사람의 실제 ID나 장애물의 원본 좌표를 경로 계획기에 전달하지 않습니다. 위치 추정 기준은 이상적인 차체 오도메트리입니다. 가까운 측면 대상은 저속 위치·방향 회복을 수행하고, 후방 대상은 안전한 관측 여유가 있을 때 최대 0.25 m/s 명령으로 후진합니다. 전후진 전환은 제동 후 수행합니다. 후방 저상 물체는 전방 ToF로 검출할 수 없으므로 실제 후진 안전을 보장하지 않습니다.

계단 정지는 별도의 안전 제한입니다.

Smart-Cart-4의 ToF는 전방을 향합니다. 이 시뮬레이터도 낙차 센서로 둔갑시키지 않습니다. 계단과 8° 초과 경사는 미리 알려진 통과 금지 지형 지도로 제한합니다. 실제 카트에서 같은 안전을 확보하려면 지면 센싱과 제동 하드웨어 검증이 추가로 필요합니다. 접촉 시 회전은 멈춥니다. 주행 중에는 중력과 관성이 작용하며, 정지 명령은 가정한 유한 제동력·주차 제동으로 유지합니다. 접촉기 개방만으로 실제 경사 정지가 보장되는 것은 아닙니다.

제조사 수치와 시뮬레이션 가정을 구분합니다.

LiDAR C1의 360°·12 m, VL53L1X의 최대 4 m·전체 FoV 27°를 범위의 기준으로 사용합니다. 브라우저에서는 LiDAR를 360개 또는 180개 광선, 10 Hz로 축약했습니다. ToF는 수평 단면의 단일 영역 거리 모델입니다. 수직 시야·바닥 반사·SPAD 수광은 재현하지 않습니다.

UWB 반경·PDoA 범위, 햇빛에서의 누락·거리 축소, 질량, 모터 토크-속도 곡선, 전류, 마찰, 제동, 보행자 행동은 조절 가능한 가정입니다. 측면·후면에서는 이전 이동 예측과 두 거리값을 융합합니다. 최초 거리값 두 개만으로 전후 모호성을 해소하지 않으며, 최초 방위 획득 실패나 신호 단절에서는 정지합니다. 실측 데이터로 보정한 디지털 트윈이 아닙니다.

경사면 운동

차량·적재 질량과 바퀴의 등가 회전 관성에 대해 구동력, 경사 중력, 구름저항, 공기저항, 제동력의 합으로 가속도를 계산합니다. 속도 제어와 구동계에는 응답 지연이 있어 경사 진입 시 속도가 즉시 고정되지 않습니다. 정지 상태에서 굴러가지 않는 것은 중력 누락이 아니라 주차 제동이며, 구동과 브레이크를 모두 해제한 시험에서는 경사 아래로 구릅니다. 사람의 양발은 지형 높이·발바닥 면적과 두 관절 역기구학으로 배치합니다. 전신 생체역학·타이어 변형·차량 전복은 재현하지 않습니다.

원본 앱과의 관계

Flutter smart_cart_app을 교체하거나 실행하지 않는 정적 웹 시뮬레이터입니다. 내보내기의 텔레메트리는 원본 파서가 읽는 필드를 유지합니다. tof.left_mm/right_mm는 최신 모델의 전방 좌·우를 의미하며 cliff:null입니다. 실제 앱으로 데이터를 보내는 서버·WebSocket은 포함하지 않습니다.
