# 1.2.0 수동 확인 절차

[English](TEST-CASES.md) · [검증 보고서](QA-KR.md)

## 동작 화면과 요약

1600×1000 또는 1366×768 크기의 브라우저에서 엽니다. 주행 속도·명령 속도·추종 설정·주행 거리·접촉 횟수가 3D 화면 **위**에 있는지 확인합니다. 하단에는 센서 표시와 이동 안내만 있어야 합니다. 이 릴리스의 Chromium/CSS 시험에서는 3D 높이가 각각 약 692px·460px였습니다. OS 글꼴·줌·창 크기에 따라 달라질 수 있습니다.

## 키를 누른 채 시점 회전

장애물 없음, 평지를 선택합니다. 3D 화면을 클릭하고 W를 누른 상태에서 1초 이상 이동합니다. W를 떼지 않고 마우스로 시점을 90~180° 돌립니다. 사람은 카메라 쪽으로 방향을 틀지 않고 같은 지형의 전방을 따라가야 합니다. W를 누른 채 C를 눌러 시점을 복귀해도 이동축이 바뀌면 안 됩니다. S·A·D와 방향키도 반복합니다. 지형 기준 전방 +Z, 후방 -Z, 좌측 +X, 우측 -X이며 좌우는 초기 후방 관측 기준입니다. 반대쪽 시점에서 화면상의 이동 방향이 반대로 보이는 것은 정상입니다.

두 반대 방향키는 상쇄되고 대각선 이동 속도는 더 빨라지지 않아야 합니다. 키를 놓거나 창에서 포커스가 나가면 입력이 해제되어야 합니다. 설정 입력란에서는 방향키가 설정 편집에 사용되고 배경 사용자는 움직이지 않아야 합니다. 모바일 방향 버튼도 회전한 시점에서 같은 고정 방향으로 이동해야 합니다.

## 보행 방향

낮은 측면 시점으로 사용자의 발을 관찰합니다. 공중에 든 발은 몸 기준 뒤에서 앞으로 내딛고, 지면을 딛는 발은 몸 기준 뒤로 이동해야 합니다. 몸의 방향은 실제 이동 방향을 따라야 합니다. 좌·우 이동과 후방 이동에서도 발의 순환이 반대로 돌아가면 안 됩니다. 자율 보행자에게도 같은 순환이 적용되는지 확인합니다. 오르막·내리막에서 발이 지면을 뚫지 않는지, 이동 경계나 카트에 막힌 보행자가 계속 제자리 보행하지 않는지도 확인합니다. 급회전과 멈춤 전환은 완전한 생체역학 접촉 해석이 아닙니다.

## 우측 실시간 데이터

어떤 펼침 항목도 누르지 않고 LiDAR·UWB·ToF의 현재 수치와 오른쪽 그래프를 확인합니다. 우측 공통 스크롤을 내려 후륜 모터 수치/전류 그래프와 전륜 조향 수치/각도 그래프도 확인합니다. 좌우 선은 실선·점선으로 구분되고 단위가 일치해야 합니다. ToF는 수치와 그래프 모두 mm입니다. 유효한 반환이 없는 경우 -- 또는 선의 공백이 정상이며 0으로 오인하면 안 됩니다. 일시정지하면 숫자와 이력이 함께 유지되어야 합니다.

520px 이하 화면에서는 그래프가 수치 아래로 내려오지만 숨겨지면 안 됩니다. 수평 페이지 스크롤 없이 그래프를 읽을 수 있어야 합니다. LiDAR 점군 보기와 상태 기록은 보조 기능으로 계속 펼침형입니다.
