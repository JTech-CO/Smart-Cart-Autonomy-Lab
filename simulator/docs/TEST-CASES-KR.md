# 1.1.1 수동 재현 검사

[English](TEST-CASES.md) · [자동 검사 결과](QA-KR.md)

기본 UI는 라이트 모드입니다. 지형·장애물 변경은 새 세션을 만듭니다. 키보드로 움직이는 것은 카트가 아닌 태그 사용자입니다.

| 오류 | 확인 절차 | 기대 결과 |
|---|---|---|
| 방향키 | 평지·장애물 없음으로 설정합니다. 3D 화면을 클릭하고 네 방향키를 누릅니다. 시점을 약 90°·180° 돌린 뒤 반복합니다. | 화면의 왼쪽·오른쪽·위·아래로 이동합니다. 재개 버튼을 클릭한 뒤에도 이동키가 작동합니다. 입력란의 방향키는 원래 입력 동작을 유지합니다. |
| 시점 회전 | 장면을 오른쪽으로 끌고, 다시 위쪽으로 끕니다. 장면 밖에서 버튼을 놓은 뒤 마우스만 움직입니다. | 오른쪽 드래그로 방위각 증가, 위쪽 드래그로 고도 증가. 드래그 종료 후에는 시점이 계속 돌지 않습니다. |
| 측면·후진 | 장애물 없이 태그를 처음 정상 획득합니다. E로 카트만 제동한 상태에서 사람을 카트 옆으로, 이어 충분한 여유를 두고 뒤쪽으로 이동합니다. E를 해제합니다. | 측면은 위치·방향 회복, 후방은 저속 후진. 우측 UWB는 거리·이력 융합을 표시할 수 있고, 후진 속도·RPM·PWM은 음수입니다. 충분히 접근하면 제동합니다. 처음부터 후방에서 방위 이력이 없는 경우와 구분합니다. |
| 발과 경사 | 5~8° 오르막·내리막, 보행자 켜짐으로 설정합니다. 발이 보이도록 시점을 낮추고 확대합니다. | 발바닥이 지면 아래로 통째로 파고들지 않습니다. 좌우 다리의 무릎 굽힘과 스윙 높이가 따로 적용됩니다. |
| 차량 관성 | 5~8° 경사에서 사용자를 이동시켜 카트를 경사로에 진입시킵니다. 적재 질량 0 kg와 65 kg를 각각 확인하고, 이동 중 E를 누릅니다. | 경사·적재에 따른 속도·가속도 과도응답과 제동 거리가 달라집니다. 정지 후 주차 제동으로 유지합니다. Space는 전체 시간을 멈추므로 물리 제동 시험에는 사용하지 않습니다. |

**자동화된 자유 구름 시험:** `node tests/bugfix.test.cjs`는 내부 물리 명령의 `coast:true, brake:false`로 구동·제동을 모두 해제한 조건도 검사합니다. 정상 자동 추종과 별도 시험이며, 정지한 카트에 중력 효과를 보여주려고 주차 제동을 강제로 없애지 않습니다. 새로운 위험한 실차 제어 버튼을 추가한 것이 아닙니다.

센서 범위 안이라는 조건만으로 모든 방위·장애물·인식 실패 상황이 해결되는 것은 아닙니다. 최초 방위 모호성, 가림, 지나치게 좁은 공간, 후방 낮은 물체 사각지대는 [모델 한계](MODEL-KR.md)에 남겨 두었습니다.
