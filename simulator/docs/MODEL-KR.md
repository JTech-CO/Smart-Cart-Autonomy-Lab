# 시뮬레이션 모델 1.2.0

[English](MODEL.md) · [출처·가정](SOURCES.md) · [검증](QA-KR.md)

## 실행 주기와 정보 경계

세계·차량은 60 Hz 고정 시간 간격, 제어기·UWB·ToF는 20 Hz, 축약 LiDAR와 이력 기록은 10 Hz로 계산합니다. 느린 화면은 최대 여섯 물리 틱만 진행하며 실제 시간 대비 모의 시간 비율을 표시합니다. 센서·물리 접촉 제한·렌더링·평가에는 세계의 실제 상태를 사용하지만, 경로 계획기는 관측된 점군, 전방 ToF, 필터링된 태그 위치와 이상적 오도메트리만 사용합니다. 장애물의 원본 좌표나 ID를 읽지 않습니다. 알려진 통과 가능 지형 지도는 별도 입력이며 지형 인식·SLAM 성능으로 주장하지 않습니다.

## 이동과 시점 좌표계

단위는 m, Y가 위쪽, yaw=0의 전방은 +Z입니다. 조작축은 지형에 고정됩니다. W·↑는 +Z, S·↓는 -Z, A·←는 +X, D·→는 -X입니다. 좌우는 초기 후방 관측 기준이며 이때 화면 오른쪽은 -X입니다. `SC.math.controlVector(right, forward)`는 X/Z에서 `(-right, forward)`를 반환하며 카메라 상태를 읽지 않습니다. `Simulation.setInput`이 대각선 속도를 정규화합니다.

키를 누른 채 시점을 돌리거나 확대·상부·상세·복귀 시점을 사용해도 이동축은 바뀌지 않습니다. 사람의 yaw는 충돌 처리 후 실제 이동 방향입니다. 1.1.1의 카메라 기준 조작 규칙을 이번 요청에 따라 명시적으로 대체합니다. 입력란의 고유 키보드 동작과 포커스 이탈·일시정지는 유지합니다.

상단 버튼에 초점이 있어도 이동키는 처리하되 Space·Enter는 버튼의 기본 동작으로 남깁니다. 입력란·선택 상자·모달은 기본 입력을 보호합니다. 포커스 이탈이나 탭 비활성화는 입력을 비우고 일시정지합니다.

## 센서와 태그 연속 추적

C1은 전방 상단 장착 위치에서 360° 단일 평면을 스캔합니다. 브라우저는 360개 또는 180개 광선을 10 Hz로 처리하며 처음 만난 표면을 관측합니다. 유효한 무반환과 무효 관측을 내부적으로 구분하지만 기존 통신 형식에서는 0으로 내보냅니다. 실제 장치의 전체 샘플링 속도를 재현하지 않으며 낮은 상자는 상부 스캔에서 누락될 수 있습니다.

BU04 두 베이스는 거리와 가정된 PDoA 범위 안의 방위를 생성합니다. 거리·방위 표본은 알파-베타 필터로 융합합니다. **이미 위치를 획득한 대상**이 PDoA 경계를 넘어가면 이전 속도로 예측한 위치와 두 거리값을 정규화된 MAP 방식으로 갱신합니다. 잡음 때문에 두 거리 원의 정확한 교점이 없어지는 경우를 곧바로 신호 소실로 처리하지 않습니다. 이 방식도 없는 정보를 만들지는 않습니다. 최초 후방 거리 두 개만으로 전후 방위를 단정하지 않으며, 위치가 0.75초 이상 오래되면 정지합니다. 가림·NLOS 오차·안테나 전파·펌웨어 호환성은 실측 검증되지 않았습니다.

사거리를 수평 거리로 투영할 때는 **후보 추정 위치**의 알려진 지면 높이와 착용 태그 높이 1.08 m 가정을 사용합니다. 제어 추정기에 사용자의 실제 좌표를 몰래 넣지 않습니다.

두 VL53L1X는 높이 약 0.312 m에서 전방을 향합니다. 27°에 걸친 수평 광선 아홉 개 중 가장 가까운 거리 하나를 반환하고, 경로 계획에는 중심선 반환과 각도 불확실성 폭을 보냅니다. 수직 광학 시야, SPAD/ROI, 바닥 반사까지 재현한 모델이 아닙니다. `tof.cliff`는 계속 null입니다. **후진 기능이 생겨도 낮은 후방 장애물이 전방 ToF에 보이는 것은 아닙니다.**

## 경로 계획과 후진

0.25 m 관측 격자, 1.3초 장애물 기억과 보수적인 차체 확장 영역을 사용합니다. A*는 대각선 모서리 관통을 금지하고 경로를 평활화합니다. 기하학적 추종 후보는 1.56초의 운동학적 예측에서 관측 장애물·이동 점군·사용자 여유를 평가합니다. 이 후보 예측은 여전히 축약된 일정 후보 속도의 자전거 모델이며 완전한 구동계 포함 MPC가 아닙니다.

거리 유지는 목표가 차체 전방 또는 후방에 정렬되고 거리 구간에 들어왔을 때 적용합니다. 가까운 측면이나 지나치게 가까운 대상은 저속 위치·방향 회복을 수행할 수 있습니다. 안전 여유가 없으면 움직이지 않으며, 사람을 피하기 위해 차체를 제자리 회전시키는 가짜 운동을 만들지 않습니다. 중심 조향 한계는 38°, 조향 응답률은 1.15 rad/s입니다. 좌우 전륜 아커만 각도와 후륜의 부호 있는 회전수를 계산합니다.

후진에서도 `yawRate = v*tan(steer)/wheelbase`를 사용합니다. v가 음수이므로 steer까지 다시 뒤집지 않습니다. 가까운 후진 경로는 차체 중심 좌표를 후륜축 기준으로 보정해 전후진이 반복되는 문제를 방지합니다. 후진 추종 **명령**은 최대 0.25 m/s, 위치 회복 후보는 0.24 m/s입니다. 실제 속도는 관성이 있는 상태값이므로 명령과 순간적으로 다를 수 있습니다.

예측 차체 네 모서리의 지형 제한과 전방·후방의 관측 제동 여유를 확인합니다. 이동 중 속도 부호를 바꿀 때는 먼저 제동합니다. 센서 소실, 경로 부재, 부족한 여유, E-stop, 접촉은 계속 정지 원인입니다. 모든 군중·사용자 궤적에서 무접촉을 보장하지 않습니다.

## 경사 종방향 동역학

차체의 지면 종방향에 대해 다음 힘을 적분합니다.

`m_eff*a = F_motor + F_gravity + F_rolling + F_drag + F_brake`

`F_gravity = -m*g*sin(pitch)`

`m_eff = m + 2*J_rear/r_rear² + 2*J_front/r_front²`

부호의 +는 **차체 전방**, −는 차체 후방입니다. 오르막을 향한 양의 피치에서는 중력이 음의 힘이 됩니다. 차체 방향을 반대로 돌리면 피치와 중력 부호도 달라집니다. 부호 있는 지면 이동거리를 cos(pitch)로 수평면에 투영하며, 전후·좌우 지면 지지 높이로 피치와 롤을 계산합니다. 6자유도 차체, 타이어 변형·미끄럼, 서스펜션, 전복·횡방향 활주 모델은 아닙니다.

| 항목 | 현재의 미교정 시뮬레이션 가정 |
|---|---|
| 공차 질량 / 적재 | 34 kg / 0~65 kg |
| 후륜 / 전륜 반경 | 0.129 / 0.066 m |
| 바퀴 한 개의 후륜 / 전륜 관성 | 0.022 / 0.003 kg·m² |
| 구름저항 / 타이어 마찰 계수 | 0.018 / 0.55 |
| 모터 포락선 | 250 W 모터 두 개의 명칭, 120 rpm 무부하 표기, 스톨 절편은 가정한 24 N·m |
| 속도 PI 비례 / 적분 이득 | 130 N/(m/s) / 70 N/m |
| 구동력 / 제동 응답 시정수 | 0.18 / 0.08 s |
| 속도 기준값 상승 / 하강률 | 0.75 / 1.20 m/s² |
| 서비스 / 주차 제동 합산 용량 | 260 / 300 N, 타이어 마찰 한계도 적용 |
| 공기저항 항 | -0.30*v*abs(v) N |

이 수치는 실물 MY1016Z, 브레이크, 타이어, 배터리의 측정 사양이 아닙니다. 모터 토크-속도, 바퀴별 출력, 접지 한계를 적용하고, 적분 누적 포화를 억제한 PI와 구동 지연을 사용합니다. 중력 부하를 정확히 알고 즉시 상쇄하는 피드포워드는 없으므로 경사 진입 시 실제 가속도·속도 과도응답이 나타납니다.

구름저항과 제동력은 운동을 반대합니다. 속도가 0을 통과할 때 정적 힘 평형이 가능하면 정지하고, 그렇지 않으면 중력에 의해 반대 방향으로 구르기 시작합니다. 구동·브레이크 해제(coast)와 정지 명령은 별개입니다. 정상 정지·E-stop에서는 가정한 제동을 요청하므로 경사에서 계속 정지해 있을 수 있습니다. 실차의 접촉기 개방을 주차 제동으로 간주하지 않습니다.

바퀴 회전 애니메이션은 부호 있는 실제 이동거리, RPM은 순간 속도로 계산합니다. 지형·접촉 제한으로 거부된 이동은 바퀴 회전과 모터 힘에 남기지 않습니다. 접촉은 별도의 충격·구속 조건이므로 순간 접촉 가속도를 매끈한 힘 항만으로 설명하지 않습니다. 모터의 음의 기계적 일은 제동 소산으로 기록하며 배터리 회생 충전 검증값으로 주장하지 않습니다.

## 지형과 사람

계단은 0.17 m 높이, 0.32 m 깊이의 여섯 단이며 옆으로 돌아갈 길이 없습니다. 계단과 8° 초과 경사는 알려진 지도에서 카트 통과를 제한하고 별도의 실제 차체 영역 검사도 적용합니다. 사용자는 올라갈 수 있습니다. 이를 전방 ToF의 계단·절벽 검출 성능으로 해석하면 안 됩니다.

사람은 기존의 개별 목표·반발력 기반 이동을 유지합니다. 시각화에서 각 신발의 바닥 영역을 지형에 지지시키고 스윙 높이를 적용합니다. 0.43 m 허벅지와 0.40 m 종아리를 두 관절 역기구학으로 연결하며, 필요할 때만 골반을 낮춰 도달 가능성을 맞춥니다. 조작 대상 사용자와 다른 보행자에 같은 계산을 사용합니다. 완벽한 접지 고정, 발 압력, 전신 생체역학을 구현한 것은 아닙니다.

상자는 마찰과 접촉 충격량에 따라 평행 이동하며 회전·전도·변형은 생략합니다. 카트 하드웨어 형상은 1.1.0과 같습니다. 서보 링크도 정밀 4절 링크 해석이 아닌 시각적 표현입니다.

## 표시와 내보내기

라이트 전용 SANE UI와 정적 WebGL 렌더러를 유지합니다. 3D 저조도는 웹 테마를 바꾸지 않습니다. 광원·센서 표시는 실측 광학 시뮬레이션이나 안전 인증이 아닙니다.

주행 요약은 상단에 두고, 각 센서·구동 항목의 왼쪽에는 수치, 오른쪽에는 최근 12초 그래프를 상시 표시합니다. 공통 스크롤로 아래쪽 항목을 확인하며 작은 휴대폰에서는 그래프가 수치 아래로 이어집니다. 후륜 수치 영역에는 가속도·중력·구동력·제동력을 둡니다. CSV·세션에 `acceleration_mps2`, `gravity_force_N`, `motor_force_N`, `rolling_force_N`, `brake_force_N`, `effective_mass_kg`, `parking_brake`를 추가합니다. 기존 Flutter 필드는 보존하며 `sim` 확장 안에 가속도·힘과 유한 제동 가정 이름을 기록합니다. 이력은 최근 모의 30분, 그래프는 12초를 유지합니다. 실차 통신·WebSocket·클라우드 저장·재생 UI는 추가하지 않았습니다.


## 1.2.0 보행 위상 수정

사용자와 자율 보행자는 충돌 처리 후 실제 이동 거리에 7.5 rad/m를 곱해 보행 위상을 진행합니다. 자율 보행자의 속도와 yaw도 실제 변위로 갱신하며 이동이 막히면 의도한 속도로 발만 계속 움직이지 않습니다. 한 발의 위상 0~π는 smoothstep으로 뒤에서 앞으로 내딛는 유각기, π~2π는 몸을 기준으로 선형으로 뒤로 이동하는 입각기입니다. 반보폭 π/(2×7.5) m는 일정한 직선 보행에서 몸의 수평 이동과 지지발의 상대 이동을 상쇄합니다. 발 들기는 앞으로 내딛는 구간에만 적용하며 팔은 반대로 흔듭니다. 기존 발바닥 지형 지지와 두 관절 IK를 유지합니다. 급회전·정지 전환·임의 지형의 완전한 접촉 잠금이나 생체역학을 보장하지 않습니다.
