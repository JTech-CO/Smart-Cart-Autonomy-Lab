## 1.2.0 - 2026-09-16

- 하단의 주행·명령 속도, 추종 설정, 주행 거리, 접촉 횟수를 상단으로 이동하고 구획 여백을 줄여 3D 화면 높이를 확보했습니다.
- 1.1.1의 카메라 기준 이동을 지형 고정축으로 변경했습니다. WASD·방향키·터치 입력이 키를 누른 채 시점을 돌리거나 복귀해도 같은 방향을 유지합니다.
- 발을 앞으로 내딛고, 지면을 딛는 발은 몸 기준 뒤로 이동하도록 보행을 수정했습니다. 실제 이동 거리당 7.5 rad 위상을 사용자·자율 보행자에 통일하고, 보행자의 방향과 위상은 충돌 처리 후 변위로 계산합니다. 발바닥 지지·두 관절 IK는 유지합니다.
- 우측 데이터는 왼쪽 수치·오른쪽 실시간 그래프로 나눴습니다. 5개 시간 그래프는 기본 표시하며 보조 점군·상태 기록만 펼침형입니다. 작은 휴대폰에서는 그래프가 아래로 이어집니다.
- 루트 소개 파일을 README.md·README-KR.md로 변경하고 내부 링크를 수정했습니다. 기존 루트 README 교체가 의도된 배포 구성입니다.
- 라이트 UI·정적 실행·센서·경로 계획·차량 동역학·텔레메트리·내보내기는 유지합니다. 원격 저장소와 물리 하드웨어는 수정하지 않았습니다.

실행한 검사와 이전 테스트의 의도적 기준 변경은 [검증 보고서](QA-KR.md)에 기록합니다.

## 1.1.1 - 2026-09-16

### 수정

1. **방향키·터치 이동**: `M.look`과 동일한 카메라 좌표계로 화면 오른쪽 축의 부호를 수정했습니다. 시점을 돌린 뒤에도 입력 방향이 유지되며, 상단 버튼에 남은 초점 때문에 이동키가 무시되지 않습니다. 입력란·선택 상자의 방향키와 버튼의 Space 기본 동작은 보존했습니다.
2. **마우스 회전**: 수평·수직 드래그 부호를 수정했습니다. 드래그 시작 시 캔버스로 초점을 옮기며, 현재 포인터 ID의 이동·종료만 처리합니다.
3. **후진·측면 추종**: 거리만 보고 모든 방향을 정지시키던 조건을 정렬된 거리 유지와 저속 위치·방향 회복으로 분리했습니다. 후진 조향의 이중 부호 반전, 후진 방향 평가, 가까운 경로의 차체 중심/후륜축 기준 차이를 수정했습니다. 후방 관측의 제동 여유와 예측 차체의 지형 제한을 검사하며 전후진 전환은 제동 후 진행합니다. PDoA 범위 밖에서는 이전 이동 예측과 두 거리 관측의 MAP 갱신으로 추적을 이어갑니다. 경사진 지형의 사거리 투영에도 추정 위치의 알려진 지면 높이를 반영합니다.
4. **경사 보행**: 허벅지·종아리·신발을 개별 부품으로 분리했습니다. 각 발바닥 영역의 높이를 지면에 맞추고 두 관절 역기구학으로 연결합니다. 사용자가 조작하는 사람과 자율 보행자에 동일하게 적용합니다.
5. **경사 동역학**: 적재 질량, 바퀴의 등가 회전 관성, 중력, 구름저항, 공기저항, 속도 PI 제어, 구동 응답 지연, 유한 서비스·주차 제동을 분리해 힘을 적분합니다. 구동·제동을 해제하면 오르막에서 정지 후 뒤로 구를 수 있습니다. 가속도와 중력 성분은 기존 후륜 패널에, 구동력·제동력은 펼침 영역과 내보내기에 표시합니다.

### 유지 사항과 검증 기준

라이트 전용 SANE UI, 정적 HTML/CSS/일반 JS 실행, 카트 하드웨어 형상, 기존 Flutter 필드를 유지했습니다. `kinematics.js`, `dynamics.js` 두 로컬 스크립트를 추가했으며 서버·CDN·빌드·런타임 패키지 의존성을 추가하지 않았습니다.

기존 적재 오르막 검사는 1,050틱이 아닌 **1,200틱 이후 z=7 m 통과**를 판정하도록 변경했습니다. 중력을 즉시 상쇄하던 모델 대신 유한 응답을 반영해 같은 시간의 도달 위치가 달라졌기 때문입니다. 경로·접촉·출력 상한·유한 수치 조건은 유지하고, 경사 진입 과도응답과 적재량별 가속도 차이는 별도 새 검사로 확인했습니다.

실행 결과는 [QA](QA-KR.md), 재현 방법은 [수동 검사](TEST-CASES-KR.md)에 있습니다. 최초 후방 거리 관측의 전후 모호성, 후방 저상 물체의 광학 사각지대, 이상적 오도메트리, 알려진 지형 제한, 미교정 모터·제동 모델은 여전히 한계입니다. 원격 저장소와 GitHub Pages는 수정하지 않았습니다.

|---|---|
